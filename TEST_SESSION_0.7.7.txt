TenchyShell 0.7.7 — Sesión de prueba aislada
===============================================

Usa estos pasos SOLO en una VM o un usuario secundario. No ejecutes
--without-explorer en la sesión principal y no modifiques Winlogon.

1. Copia a esta sesión los tres archivos descargados del GitHub Release:
   - TenchyShell-v0.7.7-test.1-win-x64.zip
   - TenchyShell-v0.7.7-test.1-win-x64.zip.sha256
   - Install-TenchyShell.ps1

2. Abre PowerShell en la carpeta que los contiene y prepara las rutas:

   $archive = '.\TenchyShell-v0.7.7-test.1-win-x64.zip'
   $checksum = (Get-Content '.\TenchyShell-v0.7.7-test.1-win-x64.zip.sha256' -Raw).Trim()
   $installer = '.\Install-TenchyShell.ps1'
   $app = Join-Path $env:LOCALAPPDATA 'TenchyShell\app'

   Si el tag publicado tiene otro nombre, reemplaza las dos rutas del ZIP.

3. Revisa la instalación sin escribir archivos ni instalar dependencias:

   & $installer -ArchivePath $archive -ExpectedSha256 $checksum -WhatIf

   El comando debe aceptar el checksum. Si falla, no continúes.

4. Instala realmente TenchyShell y las dependencias faltantes:

   & $installer -ArchivePath $archive -ExpectedSha256 $checksum

   No uses -SkipDependencies: el instalador detecta WezTerm y puede instalar
   Yazi mediante WinGet. La configuración de usuario se crea solo si aún no
   existe y se conserva en instalaciones posteriores.

5. Comprueba el resultado antes de iniciar el shell:

   & (Join-Path $app 'TenchyShell.exe') --check

   Continúa solo cuando terminal, PowerShell, Yazi y navegador aparezcan como
   [OK]. Corrige cualquier advertencia antes de probar sin Explorer.

6. Inicia el perfil de prueba sin Explorer:

   $withoutExplorerConfig = Join-Path $app 'TenchyShell.without-explorer.example.toml'
   & (Join-Path $app 'TenchyShell.exe') --without-explorer $withoutExplorerConfig

   Escribe exactamente DETENER cuando el programa lo solicite. Explorer se
   cierra solo después de registrar el hotkey de recuperación.

7. Verificaciones mínimas con Explorer detenido:

   - Ctrl+Alt+Space: abrir/cerrar launcher.
   - Ctrl+Alt+Enter: abrir WezTerm.
   - Ctrl+Alt+E: abrir Yazi.
   - Ctrl+Alt+B: abrir el navegador configurado.
   - Ctrl+Alt+T: abrir/cerrar bandeja propia con Escape.
   - Ctrl+Alt+Shift+E: recuperar Explorer.

   Después de recuperar Explorer, confirma que vuelve a ejecutarse y que la
   bandeja de TenchyShell no lo inicia por sí misma.

8. Cierre seguro:

   - Pulsa Ctrl+Alt+Shift+E si Explorer todavía no se ha recuperado.
   - Cierra TenchyShell con Ctrl+C en la consola donde se inició.
   - Cierra sesión e inicia de nuevo este usuario de prueba. Explorer debe
     iniciar normalmente: TenchyShell no modifica Winlogon.

No ejecutes desde esta guía comandos de logout, apagado, reinicio ni cambios
del registro de Winlogon.
