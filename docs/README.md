# Documentación de TenchyShell

Esta carpeta reúne la documentación canónica del MVP 0.7.11. El
[`README` principal](../README.md) es el punto de entrada corto; estas guías
explican cómo instalar, usar, operar y mantener el proyecto.

| Guía | Para qué sirve |
| --- | --- |
| [Instalación](INSTALLATION.md) | Requisitos, release, fuente, actualización y desinstalación. |
| [Uso y configuración](USAGE.md) | Flujo diario, hotkeys y referencia TOML. |
| [Arquitectura](ARCHITECTURE.md) | Componentes, dependencias y límites del diseño. |
| [Desarrollo](DEVELOPMENT.md) | Compilación, pruebas, scripts, publicación y MSIX. |
| [Operación segura](OPERATIONS.md) | Sesiones sin Explorer, recuperación, logs y límites conocidos. |
| [Notificaciones](NOTIFICATIONS.md) | Bridge MSIX, permiso por usuario y diagnóstico. |
| [Pruebas manuales](MANUAL_TESTING.md) | Checklist funcional de Windows 11. |
| [Rendimiento](PERFORMANCE.md) | Protocolo reproducible de medición. |
| [Optimizaciones](OPTIMIZATIONS.md) | Decisiones y resultados de rendimiento. |

Las guías se mantienen en español. Los comandos están pensados para PowerShell
en Windows 11 Pro.
